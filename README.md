# Coffee Shop Sales Analysis

An Excel dashboard analyzing sales data from a NYC coffee shop chain with 3 locations — built to find peak hours, top products, and store performance patterns.

## The dashboard helps analyze:

- Total sales
- Product demand
- Sales trends
- Customer buying patterns
- Time-based performance

## What's in it

- **Dashboard** — Visual summary with average bill and order metrics
- **Quantity by Hour** — What time of day gets the most orders
- **Product Type** — Which drinks/items sell the most
- **Store Location** — Sales and transaction count per store
- **Size Preference** — Large vs Regular vs Small sales
- **Weekday Analysis** — Which days are busiest
- **Category** — Coffee vs Bakery vs Tea vs Branded breakdown

## Tools Used

- Microsoft Excel
- Pivot Tables
- Charts & Slicers
- Dashboard design

## Data Overview

| Column | Description |
|--------|-------------|
| transaction_date / time | When the order was placed |
| store_location | Astoria, Hell's Kitchen, Lower Manhattan |
| product_category | Coffee, Tea, Bakery, Branded |
| product_type | Specific item ordered |
| transaction_qty | Number of items |
| unit_price / total_bill | Pricing info |
| Hour / Day of Week | Time-based columns for analysis |

## Key Insights

- Peak hours are between **8 AM – 10 AM** (morning rush)
- **Coffee** is the top category by revenue by a large margin
- All 3 stores perform similarly — Hell's Kitchen slightly leads
- **Barista Espresso** is the highest selling product type
- Average bill per transaction is around **$4.69**

## What I Learned

- How to work with time-based data (hour, weekday, month)
- Building pivot tables to analyze patterns across different time periods
- Comparing multiple store locations side by side in a dashboard
- Extracting operational insights like peak hours from raw transaction data
- Organizing a clean report sheet alongside the dashboard

## Recommendations

- Staff more during **8 AM – 10 AM** — that's when orders spike
- **Promote bakery items** alongside coffee — they pair well and can increase average bill
- Hell's Kitchen and Astoria are close in sales — investigate what Lower Manhattan can do differently
- Push **large size** options more — they generate the highest revenue
- Consider weekday-specific deals since traffic is fairly even — a slow-day promo could boost numbers

## How to use

Download the `.xlsx` file and open in Excel (2016 or later). Use slicers to filter by month or store location.
